# E2 - World-1 accelerators across regimes (measured)

All minimize the SAME symmetric-Dirichlet energy. Same criterion (|g|inf<1e-6). Two regimes, because World-1 superiority claims are regime-specific. Run: `python -m bench.run_e2`.

## well-conditioned (perturbation)

| method | iters / status | global factorizations | wall (ms) |
|---|---|---|---|
| newton | 7 it | 7 | 414.0 |
| l-bfgs | 40 it | 0 | 378.0 |
| sobolev-lbfgs | 42 it | 1 | 595.8 |
| aqp | 666 it | 1 | 12228.0 |
| gradient-descent | 185 it | 0 | 5835.8 |
| adam(lr=.01) | 266 it | 0 | 2436.9 |

## ill-conditioned (3x stretch)

| method | iters / status | global factorizations | wall (ms) |
|---|---|---|---|
| newton | 5 it | 5 | 308.8 |
| l-bfgs | 55 it | 0 | 514.2 |
| sobolev-lbfgs | 34 it | 1 | 481.9 |
| aqp | 218 it | 1 | 3940.7 |
| gradient-descent | 361 it | 0 | 9951.1 |
| adam(lr=.01) | 348 it | 0 | 3153.4 |

## Observed -- two claims decomposed

- **Sobolev preconditioning is a REAL, regime-specific win (validates a BCQN component).** In the ill-conditioned regime Sobolev-L-BFGS (34 it) beats plain L-BFGS (55 it); in the well-conditioned regime it does not (42 vs 40). So the D0=L^-1 Sobolev-init component helps *exactly* where it's designed to (ill-conditioning) -- hardens the Sobolev-init claim as **`qualified`** (regime-dependent).
- **The AQP-beats-L-BFGS claim does NOT reproduce here.** AQP loses to L-BFGS in BOTH regimes (666 vs 40 well; 218 vs 55 ill). The paper's ~200x AQP-over-L-BFGS number was against a MATLAB L-BFGS baseline; against a well-implemented L-BFGS the advantage vanishes. This is the classic **baseline-quality confound** ('did the method beat a *tuned* generic optimizer?' -- here, no) -- flag `aqp->l-bfgs` as **confound-borne / unreproduced** in this harness. (AQP's genuine claim is mesh-independent iteration count + cheap per-iter, not raw iterations vs L-BFGS.)
- **Second order still wins iterations -- but iterations are not free:** Newton takes only 7/5 iters, yet **each is a full Hessian factorization** (7/5 of them), whereas AQP and Sobolev-L-BFGS prefactor a fixed operator **once** and L-BFGS never factorizes. So the low Newton iteration count is the expensive kind; the factorizations column is the honest HW-independent cost that iteration-count alone hides, and it is why wall-clock does not track iterations (E4).

_Caveat: dense Newton; single mesh/seed per regime. We report THREE axes per method -- iterations, global factorizations (HW-independent cost), and wall-clock (HW-dependent) -- because no single one settles a cross-method verdict (docs/metrics.md). AQP's mesh-independence claim (vs its L-BFGS-speed claim) is a separate, still-open test (#29)._
